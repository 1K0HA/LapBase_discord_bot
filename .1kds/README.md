# Служебные данные 1KDS

`runtime.env` — зафиксированный manifest локального runtime/bootstrap.

Каталог `state/` создаётся launcher-ом локально и хранит только hashes/служебное состояние.
Начиная с v1.0.28 там также находится `lapbase.lock`: файл metadata для OS-level
single-instance lock. Наличие файла само по себе не означает, что процесс запущен.
Секреты в `.1kds/` не сохраняются.

`uv.lock` должен храниться в корне проекта и коммититься в Git. Если он отсутствует в
первой сборке, launcher создаёт его один раз из полностью зафиксированных прямых зависимостей
и фиксированного `exclude-newer`, после чего последующие запуски используют `uv sync --frozen`.
